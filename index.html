      קובץ הסיכום

      המשך ב־Todoist

      ההרגלים ייכנסו לפרויקט "הרגלים" כמשימות חוזרות, לפי הימים והשעות שקבעת. משם ממשיכים לעקוב, גם מהווידג'ט במסך הבית.

      1. פותחים את ההגדרות של Todoist (באפליקציה: הגדרות, ואז Integrations, ואז Developer).
      2. לוחצים Copy API token ומדביקים כאן.

      הטוקן נשלח ישר ל־Todoist, רק לשליחה הזאת, ולא נשמר בשום מקום.

      סדר את הטלפון

      מכאן ממשיכים ב־Todoist, ישר ממסך הבית. כל הרגל הוא משימה חוזרת: מסמנים עיגול, והיא קופצת לפעם הבאה.

      1. מורידים את Todoist בחינם ושולחים אליו את התוכנית (שלב 4). לעמוד ההורדה
      2. מוסיפים את הווידג'ט הגדול של Todoist לראש מסך הבית, ובוחרים בו את הפרויקט "הרגלים".
      3. משאירים רק 8 אפליקציות שבאמת פותחים כל יום. על כל השאר: לחיצה ארוכה, "הסר אפליקציה" ואז "הסר ממסך הבית". הן לא נמחקות.
      4. מסתירים את שאר המסכים: לחיצה ארוכה על מקום ריק, לוחצים על הנקודות שמעל ה־Dock, ומורידים את הסימון מכל מסך חוץ מהראשון.
      5. צריך אפליקציה אחרת? מחליקים למטה באמצע המסך ומחפשים אותה.

      באנדרואיד: לחיצה ארוכה על אפליקציה ו"הסר" (לא "הסר התקנה"). היא נשארת במגירת האפליקציות.

      תראה לי איך מוסיפים וידג'ט

      1. 1. לוחצים לחיצה ארוכה על מקום ריק במסך הבית, עד שהאפליקציות רועדות.

      2. 2. לוחצים "ערוך" בפינה, ואז "הוסף וידג'ט". בגרסאות ישנות יש כפתור +.

      3. 3. מחפשים Todoist, מחליקים לגודל שנוח לך, ולוחצים "הוסף וידג'ט".

      4. 4. לחיצה ארוכה על הווידג'ט, "ערוך וידג'ט", ובוחרים את הפרויקט "הרגלים". מסמנים עיגול כשעשית.
